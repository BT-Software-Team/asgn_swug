# AmplideX® One Reporter

**Release Configuration v2.0 · Software User Guide**

> **Research Use Only.** Not for use in diagnostic procedures.

---

The AmplideX® One Reporter and AmplideX Nanopore Carrier Plus Analysis Module (collectively, "the Software") are a data analysis and visualization tool designed to interpret long-read sequencing FASTQ files generated with Asuragen Carrier Plus kitted products.

## Compatible Sequencing Instruments

The Software is compatible with the following Oxford Nanopore Technologies instruments:

- MinION® Mk1B® or Mk1D®
- GridION®
- PromethION®

## MinKNOW Compatibility

The Software analyzes demultiplexed FASTQ outputs generated by MinKNOW®. Each new MinKNOW release is evaluated internally to ensure updates do not affect raw data acquisition or variant detection — depending on the nature and potential impact of the changes, validation may include wet-lab or in-silico experiments. When necessary, a new Software release is issued to maintain compatibility with the latest MinKNOW version. Compatibility status is displayed during analysis configuration.

For instructions on analyzing data from older MinKNOW versions, see [Post-run Basecalling](running-an-analysis/post-run-basecalling.md).

## Default File Locations

Everything the Software writes lives under a single **User Data Path**, which differs by operating system:

| | Linux (Ubuntu 22.04) | Windows 11 |
|---|---|---|
| **User Data Path** | `/var/lib/asuragen` | `C:\ProgramData\asuragen` |

Unless you changed the User Data Path during installation, the locations below apply. `{Analysis Id}` is the name you gave the analysis when you created it.

| What | Linux | Windows |
|------|-------|---------|
| **Analyses** (all) | `/var/lib/asuragen/analyses` | `C:\ProgramData\asuragen\analyses` |
| **Results** for one analysis | `/var/lib/asuragen/analyses/{Analysis Id}/results` | `C:\ProgramData\asuragen\analyses\{Analysis Id}\results` |
| **Logs** for one analysis | `/var/lib/asuragen/analyses/{Analysis Id}/results/logs` | `C:\ProgramData\asuragen\analyses\{Analysis Id}\results\logs` |
| **Imported datasets** | `/var/lib/asuragen/datasets` | `C:\ProgramData\asuragen\datasets` |
| **Default panel filters** | `/var/lib/asuragen/panels/default` | `C:\ProgramData\asuragen\panels\default` |
| **Custom panel filters** | `/var/lib/asuragen/panels/custom` | `C:\ProgramData\asuragen\panels\custom` |
| **Sequencing run data** (default data source) | `/var/lib/minknow/data` | `C:\data` |
| **Installation directory** | *(managed by the package manager)* | `C:\Program Files\asuragen` |
| **Docker image pull log** | `/var/log/asgn-carrier-plus-images.log` | `C:\Program Files\asuragen\carrier-plus-images.log` |
| **Database backup** (created at uninstall) | Docker volume `/var/lib/docker/volumes/file_interface_vol` | SQL dump in `C:\ProgramData\asuragen` |

> **On Windows, `C:\ProgramData` is hidden by default.** To browse to it in File Explorer, turn on hidden items under **View**, or paste the path directly into the address bar.

> **Where results are written vs. where run data is read.** Sequencing run data stays where the instrument wrote it; the Software copies a dataset into the User Data Path when you import it. See [Data Storage & Archival](reference/data-storage.md) for managing both.
