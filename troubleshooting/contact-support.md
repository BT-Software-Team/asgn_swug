# Contact Support

If a problem isn't resolved by [Common Errors](common-errors.md), Asuragen Technical Support can help. Gathering a few files before you reach out lets support diagnose the issue on the first pass.

## Before you contact support

Check [Common Errors](common-errors.md) first — most installation, analysis, and dataset issues have a documented fix there.

## What to gather

For an analysis or results problem, collect the following (all under `[User Data Path]\analyses\{Analysis Id}\results\`):

| Item | Where to find it |
|------|------------------|
| **Analysis Id** | The name shown on the Analysis Dashboard |
| **Software version** | Click the **About** button in the Software |
| **Run log** | `logs/run.log` |
| **Failed processes log** | `logs/failed_processes_log.txt` |
| **Error output** for a failed process | `logs/errors/{hash}/.command.err` |
| **QC failures** (for blank/empty results) | `quality_control/quality_control_fail.csv` |
| A screenshot of any on-screen error message | — |

> **Tip:** For an installation problem instead, note your operating system and version, and confirm outbound HTTPS access to the [required endpoints](../getting-started/system-requirements.md#network-requirements).
